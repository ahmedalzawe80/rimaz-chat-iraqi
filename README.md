# دردشة ريماز عراقية

نسخة مشروع Node.js + Express + Socket.IO مهيأة للرفع على GitHub ثم تشغيلها على استضافة تدعم Node.js وWebSockets.

## التشغيل

```bash
npm install
npm start
```

الخادم يستخدم المنفذ الموجود في `PORT` أو 3000 افتراضياً.

## قواعد الموقع

- الغرفة العامة: كتابة نص فقط.
- غرفة الصوت/المايك منفصلة.
- الخاص يدعم الوسائط والمكالمات عند بلوغ 500 إعجاب وفق الصلاحيات الموجودة في المشروع.
- إرسال التنبيهات يفتح عند 400 إعجاب.
- الإعجاب: مرة كل 10 ثوانٍ.
- الزائر مؤقت، والعضو المسجل محفوظ في البيانات الحالية.
- أدوات زيادة الإعجابات وإدارة الغرف للمشرف.

> ملاحظة: هذه النسخة تحتوي على أساس WebRTC للإشارات والمكالمات الخاصة، ويجب اختبارها بعد النشر على HTTPS، وقد تحتاج TURN في بعض الشبكات. كما أن `data.json` والتخزين المحلي للملفات ليسا مناسبين كقاعدة بيانات/تخزين إنتاجي دائم على خدمات الاستضافة التي تستخدم نظام ملفات مؤقت؛ سيتم نقل البيانات والتخزين إلى خدمات دائمة في خطوات النشر التالية.
